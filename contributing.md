# Contributing Guidelines

Know another awesome API, project, library, app, or tool that is missing from this list? Open a pull request or file an issue. Everyone's contributions are always welcome!

## Guidelines
- Add one link per Pull Request.
- Add the link follow:
`- [project-name](http://example.com/) - A short description (Keep descriptions concise).`
- Add a section if needed.
    - Make sure the section title is **Bold** style.
    - Add the section description.
    - Add the section title to Table of Contents.
- Search previous suggestions before making a new one, as yours may be a duplicate.
- Check your spelling and grammar.
- Remove any trailing whitespace.

## Licence requirements
- **Software** must be released under an [OSI-approved](https://opensource.org/licenses) or [FSF-approved](https://www.gnu.org/licenses/license-list.html) free and open source licence, with a licence file in the repository.
- **Datasets** must use an open data licence: [CC0](https://creativecommons.org/publicdomain/zero/1.0/), [CC BY](https://creativecommons.org/licenses/by/4.0/) or [ODbL](https://opendatacommons.org/licenses/odbl/).
- **Websites and communities** must be about open source projects.
- State the licence in your pull request.

Entries added before these requirements are kept. Those without a detectable licence are marked "no licence" on [awesome-agriculture.gdf.org.au](https://awesome-agriculture.gdf.org.au/) and are [under review](https://github.com/growingdatafoundation/awesome-agriculture/issues/4) until 9 May 2027. If you maintain one of them, adding a licence file is the quickest fix.
